  DASHBOARD — kort guide
═══════════════════════════════════════

Du har allerede variabler på Vercel-projektet "Dashboard".
Du behøver IKKE sætte dem op igen.

Gør kun dette:

1. Merge PR #2 på GitHub (nyt dashboard-design)

2. Vercel → Dashboard-projektet → Settings → General
   Root Directory: dashboard
   (kun hvis projektet er koblet til Bennys-Bot repo)

3. Vercel → Deployments → Redeploy

4. Bot .env på Cybrancee — tjek disse findes:
   DASHBOARD_ENABLED=true
   DASHBOARD_APP_URL=https://project-jg1cq.vercel.app

Færdig. Ingen ny auto-deploy eller ekstra opsætning.

Bot-download (som før):
https://github.com/Clapshq/Bennys-Bot/releases/latest/download/bennys-upload-linux-LATEST.tar.gz
