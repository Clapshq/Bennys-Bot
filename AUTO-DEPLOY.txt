═══════════════════════════════════════════════════════════════
  AUTO-DEPLOY — uden terminal / uden kommandoer
  Kun klik i browser (GitHub + Vercel)
═══════════════════════════════════════════════════════════════

───────────────────────────────────────────────────────────────
  TRIN 1 — Merge dashboard til main (GitHub website)
───────────────────────────────────────────────────────────────

1. Gå til: https://github.com/Clapshq/Bennys-Bot/pull/2
2. Klik **Merge pull request** → **Confirm merge**

Færdig. Bot-release pakkes automatisk af GitHub (ingen kommandoer).

───────────────────────────────────────────────────────────────
  TRIN 2 — Dashboard auto-deploy (Vercel website)
───────────────────────────────────────────────────────────────

Gør dette ÉN gang i browseren på vercel.com:

1. Log ind på https://vercel.com
2. Klik **Add New…** → **Project**
3. Vælg GitHub-repo **Clapshq/Bennys-Bot** (forbind GitHub hvis spurgt)
4. Under **Root Directory** → klik **Edit** → skriv:  dashboard
5. Framework: Next.js (findes automatisk)

6. Under **Environment Variables** — indsæt (kopier fra bot .env):

   NEXT_PUBLIC_APP_URL     = https://project-jg1cq.vercel.app
   DISCORD_CLIENT_ID       = (samme som bot)
   DISCORD_CLIENT_SECRET   = (fra Discord Developer Portal)
   DISCORD_GUILD_ID        = (samme som bot)
   DISCORD_BOT_TOKEN       = (samme som DISCORD_TOKEN i bot)
   SUPABASE_URL            = (samme som bot)
   SUPABASE_SERVICE_ROLE_KEY = (samme som bot)
   SESSION_SECRET          = (vælg en lang tilfældig streng, min 32 tegn)
   DASHBOARD_STAFF_ROLES   = Mekaniker,Lærling,Ledelse,Med-ejer,Stifter

7. Klik **Deploy**

EFTER DET: Hver gang der pushes til **main** på GitHub, opdaterer
Vercel dashboardet AUTOMATISK. Du behøver ikke gøre mere.

───────────────────────────────────────────────────────────────
  TRIN 3 — Discord OAuth (Discord website)
───────────────────────────────────────────────────────────────

1. Gå til https://discord.com/developers/applications
2. Vælg jeres bot-app → **OAuth2** → **Redirects**
3. Tilføj:
   https://project-jg1cq.vercel.app/api/auth/callback
   (eller din Vercel-URL hvis den er anderledes)

───────────────────────────────────────────────────────────────
  TRIN 4 — Bot .env på Cybrancee (File Manager)
───────────────────────────────────────────────────────────────

I bot .env på serveren (rediger filen i panel — ingen konsol):

   DASHBOARD_ENABLED=true
   DASHBOARD_APP_URL=https://project-jg1cq.vercel.app

Genstart botten.

───────────────────────────────────────────────────────────────
  BOT DOWNLOAD (automatisk efter merge til main)
───────────────────────────────────────────────────────────────

https://github.com/Clapshq/Bennys-Bot/releases/latest/download/bennys-upload-linux-LATEST.tar.gz

Upload filen i Cybrancee File Manager → start bot.
Botten udpakker og opdaterer selv.
