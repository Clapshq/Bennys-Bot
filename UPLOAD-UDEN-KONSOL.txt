╔══════════════════════════════════════════════════════════════╗
║  UPLOAD — OVERSKRIVER AUTOMATISK (ingen konsol)              ║
╚══════════════════════════════════════════════════════════════╝

1) STOP botten

2) File Manager → upload DENNE fil til /home/container:

   bennys-upload-linux-LATEST.tar.gz

   (du behøver IKKE slette handlers, commands osv. — botten gør det)

3) BEHOLD kun:
   • data/
   • .env

4) START botten

   Ved start:
   • sletter gamle handlers, commands, utils, core osv.
   • udpakker tar.gz automatisk
   • genstarter med ny kode
   • registrerer slash-kommandoer (/løn, /udbetal …)

5) Tjek loggen:
   [update] Udpakker bennys-upload-linux-LATEST.tar.gz
   [deploy] Slash-kommandoer registreret ved opstart
   [bennys] Benny's bot online (build: løn/support)

6) Genindlæs Discord (Ctrl+R) → test /løn og /udbetal

═══════════════════════════════════════════════════════════════

Startup i panelet (Settings → Startup Command):

   npm start

Første gang fra gammel bot? Sæt midlertidigt til:

   if [ -f bennys-upload-linux-LATEST.tar.gz ]; then tar -xzf bennys-upload-linux-LATEST.tar.gz; fi && node start.js

(Efter første succes kan du skifte til bare: npm start)
